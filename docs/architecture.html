Architecture Overview

Factory Inventory Management System

Full-stack demo app — Vue 3 SPA over a FastAPI REST backend with in-memory mock data. No database, no auth; state resets on server restart.

Three layers: a browser SPA, a REST API, and JSON files loaded into memory at startup.

Data Flow

One shared filter state drives every view; all filtering happens server-side in Python.

1FilterBarUser picks period / warehouse / category / status
→
2useFiltersModule-scope refs — a singleton shared by all views
→
3api.jsFilters become query params; 'all' values are omitted
→
4FastAPIapply_filters + filter_by_month over in-memory lists
→
5Pydanticresponse_model validates & shapes the JSON
→
6ViewRaw data in refs → computed properties → SVG charts & tables

Observations & Gotchas

Frontend/backend API mismatch.api.js defines task CRUD and purchase-order calls with no matching FastAPI routes — those UI features will 404. The CreatePurchaseOrderRequest Pydantic model exists but no endpoint uses it, and purchase_orders.json is empty.
Backlog.vue is orphaned.The view exists (152 lines) but has no route in main.js — it's unreachable from the UI.
Everything is ephemeral.Data is loaded once at import; nothing writes back to disk. Restarting the server resets all state.
Dates are hardcoded to 2025.QUARTER_MAP and the reports endpoints only recognize 2025 months — data outside 2025 silently disappears from quarterly views.
Dashboard.vue is the giant.1,271 lines — by far the largest view (next is Spending at 852). Global styles also live in App.vue.
Auth & i18n are cosmetic.useAuth serves a hardcoded mock user (en/ja aware); there is no real authentication anywhere.
